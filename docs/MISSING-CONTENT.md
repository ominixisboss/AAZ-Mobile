# What is still missing, page by page

Derived from the book's own table of contents, which is a complete index. Nothing
here is guesswork about *what exists* — only the contents of these pages are unknown.

**118 of ~151 pages** are still missing. But you do not need all of them, and the
order below is by leverage, not by page number.

## Tier 1 — 2 pages that unlock combat

| Pages | Section | Why it matters |
| --- | --- | --- |
| 142 | Weapons Summary Table | Attack modifiers, Fire Rate, Rusted status |
| 143 | Protective Suits Summary Table | Defense bonuses, resistances, artifact slots, carry bonuses |

`Combat` already accepts every one of these — weapon modifiers, FR bursts, jam on
Rusted, suit Defense bonus, the −1 for going unarmoured. It has nothing to feed it.
**Two pages makes combat runnable end-to-end.**

## Tier 2 — 10 pages that unlock character creation

| Pages | Section |
| --- | --- |
| 104–107 | Junk Table |
| 108–111 | Supplies Table |
| 112–113 | Weapons Table |

Creation rolls one item on each of these plus d6 Food and d6×10 rubles. Everything
else about creation is already implemented. With these, an operative can be rolled up
for real.

## Tier 3 — ~5 pages for a playable vertical slice

Pick **one** terrain table and **one** encounter table and the whole loop runs:

| Pages | Section | Note |
| --- | --- | --- |
| 50–52 | Broken Roads | The most likely terrain at 16.7%, so the best one to build first |
| 100–101 | Anomalies | Shortest encounter table at 2 pages |

Tiers 1–3 together are **~17 pages** and produce a genuinely playable slice.

## A likely typo in the printed contents

The table of contents and the Exploration Table disagree about where two terrain
tables begin:

| Table | Contents says | Exploration Table says |
| --- | --- | --- |
| Industrial Ruins | p. 49 | p. 47 |
| Military Installations | p. 58 | p. 56 |

The cross-references are almost certainly right. Taking them, the nine terrain tables
start at 38, 41, 44, 47, 50, 53, 56, 59, 62 — **exactly three pages apart**, and the
last one ends precisely where Locations & Characters begins on p. 65. Taking the
contents instead gives spans of 3, 3, 5, 1, 3, 5, 1, 3, 3, which would mean two
one-page terrain tables sitting between five-page ones.

So: every terrain table is 3 pages, and the contents has two typos.
